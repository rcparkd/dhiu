# DHIU Website Recreation

A responsive Next.js + Tailwind CSS project inspired by the public homepage of Darul Huda Islamic University (DHIU).

## Requirements
- Node.js 20.9+ (Node 22 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## What's included
- Responsive navigation with a mobile menu
- Hero section, announcements and quick links
- News and events section
- About, mission, vision and philosophy
- Institutional cards and university statistics
- Student life, Vice Chancellor message, admissions callout
- Contact details and footer

## Notes
This is a front-end recreation, not the university's official website. Some photos are remote illustrative images and may need replacement with approved DHIU assets for a closer visual match. Links to portals and original pages point to the official website where possible. Admissions, search, portal authentication and any backend workflows are not replicated.
